# Librerías y herramientas

Utilizamos las funciones incluidas en el core AVR de Arduino para leer A0, controlar el LED y comunicarnos por serial. Para guardar datos y visualizar el histórico utilizamos pyserial, pandas y Streamlit.

Las dependencias están en [requirements.txt](../dashboard/requirements.txt) y sus referencias en [FUENTES.md](../../FUENTES.md).
