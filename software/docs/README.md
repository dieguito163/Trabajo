# Calibración

1. Registrar diez lecturas de ADC en tierra seca y diez en tierra húmeda, en condiciones comparables.
2. Identificar si lectura ADC aumenta o disminuye con sequedad.
3. Fijar umbral entre intervalos y validar en distintas macetas/tipos de tierra.
4. Verificar polaridad del LED y del módulo usado en el prototipo.

El software entregado es una propuesta, no resultados de calibración real.
