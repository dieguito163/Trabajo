# STL listos para impresión

Los STL se **generan en GitHub Actions** desde el CAD paramétrico. Ir a Actions → `Generar STL imprimibles` → Run workflow; al terminar, descargar el artefacto `caja_detector_humedad_STL` con tres piezas (`base_arduino_uno.stl`, `tapa_led.stl`, `probeta_ajuste.stl`). También se puede exportar desde OpenSCAD local. No imprimir el modo `vista`.
