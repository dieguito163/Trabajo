# Fotografías de nuestro detector

Tomamos tres fotografías del prototipo desde distintos ángulos para mostrar cómo quedó la carcasa, la tapa con tornillos y la conexión con el sensor de humedad.

![Nuestro detector desde tres perspectivas](vistas_del_montaje.jpg)

En estas vistas se aprecia la sonda conectada por fuera de la carcasa y la tapa desmontable. Podemos abrir la caja retirando los tornillos para revisar los componentes y modificar las conexiones si fuera necesario.
